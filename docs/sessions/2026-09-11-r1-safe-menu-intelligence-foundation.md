## Security decisions

- Tenant and authenticated user identity are derived server-side from the existing auth context.
- Existing menu content remains grounded in saved tenant data.
- AI output is schema-validated before feature-level use.
- All user-supplied model content is treated as untrusted data; embedded instructions are not authoritative.
- Allergen suggestions remain owner-review assistance and are not treated as food-safety certification.
